# Methodology

- Compiled an AI-assisted ground-truth draft (ground_truth/cases.md, 2026-10-11): 13 candidate cases (~68 primary-quoted hops, ~12 unsupported), 17 negative controls, and a rejected list; fcc.gov, justice.gov and sec.gov were unreachable, so quotes come from govinfo, Justia, FindLaw and vLex copies, and nothing is verified until the user checks each hop.
- Drafted the data model (docs/data_model.md, 2026-10-11) from the decisions log: a statement-based schema where raw source records are never edited, every fact traces to a source, and matches, inferred links and metrics are computed on top.
- Set up the teleownermap Python package (2026-10-20): AGPL-3.0 license text from gnu.org, pyproject with DuckDB/networkx/numpy, a DuckDB schema implementing docs/data_model.md with database-level checks (e.g. sensitive fields can't hold plain values, documented links must cite a source record), and 7 passing tests.
- Implemented the ownership metrics (src/teleownermap/metrics/ownership.py, 2026-10-20): an absorbing Markov chain over equity stakes × link confidence with per-company "unknown owner" endpoints, giving owner probabilities, Shannon entropy (all endpoints and known-only), anonymity set size, and hop distribution, evaluated at both ends of share ranges with an optional midpoint; control links are analyzed separately as unweighted reachability. Verified with 13 tests on hand-computed examples, including cross-holding loops.
- Revised the metrics (2026-10-20): ranges now report true lower and upper bounds (all range-end combinations, plus numerical search for entropy, which can peak mid-range); publicly traded companies' unaccounted share is labeled "public shareholders"; source disagreements on shares or confidence are listed with results. 24 tests pass. Added a GitHub Actions ruff lint check.

- Settled the timing-analysis design (2026-10-25): percentile scoring of pair-timing and lead-time gaps within user-chosen comparison groups, limited to event types present in FCC/GLEIF data, shown as evidence only (never feeding match scores or metrics), primarily for pairs already linked by other evidence. Held-out cases were deliberately not used to shape these choices.

- Surveyed FCC and GLEIF bulk data (2026-10-26/27): the weekly ULS `owner.zip` (6.9 MB) holds Form 602 and Form 175 records from 2002–2026 in six record types and lists 17,446 exhibit attachments (across 10,430 filings) without including them; GLEIF's golden copy has 3.47M LEI records, 492k parent relationships and 6.4M reporting exceptions (CC0). - Tested automated exhibit download with an honest crawler label (2026-10-27): wireless2.fcc.gov refused every self-identified request with HTTP 403, including its robots.txt and the public license search page, while data.fcc.gov (bulk files) and GLEIF accepted it; the crawler was shelved. - Read GLEIF's RR-CDF 2.1 schema (2026-10-27): the relationship percentage is defined only as a quantity measured by `ACCOUNTING_CONSOLIDATION` in `PERCENTAGE` units, not as equity. Profiled the relationship file (492k links: fund-managed 153k, ultimately consolidated 134k, directly consolidated 127k, sub-fund 75k, branch 2k, feeder 1.4k; ~33k with a percentage; ~30% from lapsed LEIs) and the reporting exceptions (6.4M; mostly natural persons, non-consolidating, no known person).
- Added `teleownermap.ingest.download` (2026-10-27): downloads bulk files into `data/snapshots/<source>/<publisher date>/` with an honest User-Agent, at least 1 s between requests, stopping on HTTP 403/429; records SHA-256 and metadata and registers each file in `sources`; skips editions already downloaded. First FCC snapshot: 9 files, license files dated 2026-10-25 and application files 2026-10-24. 46 tests pass.
- Read the Form 602 instructions (May 2014) and FCC's ownership table definitions (2026-10-27): Item 7's percentage is the "ownership percentage"; indirect interests are multiplied along the chain but any link over 50% or controlling is reported as 100%, so the 2004 AT&T Wireless filing lists DCM Capital, NTT DoCoMo and NTT each at 16% for one stake. FCC's code list doesn't define `type_entity`, `filing_type` (C/P) or `filing_status` codes. The bulk file keeps only each filer's current filing (17,755 of 17,935 filers have one filing; the other 180 have one Form 602 and one Form 175).
- Added the Form 602/175 parser `teleownermap.ingest.fcc_owner` and keyed address hashing `teleownermap.ingest.hashing` (2026-10-27), plus a `labels` column on `relationships`. On the 2026-10-25 owner.zip it loads 274k records in about 16 s: 332 records broken across lines are rejoined and 2 filer rows with an extra `|` are skipped and reported; 17.3k direct shareholdings, 27.1k control links (directors, officers, key management, management contracts), 17.8k named indirect holders and 164.5k named holdings (the 18.9k H rows with no holder FRN stay as records only), 29.7k hashed person addresses with no street, city or ZIP left in the raw records. The AT&T filing loads as DCM 16% direct equity with DoCoMo and NTT as named indirect holders of up to 16%. 61 tests pass.
- User checked the City of Bastrop's filing in ULS (2026-10-27): code "b" is displayed as "Government Entity" (incorporated under Texas law). The parser now types code-b parties as `government` and lets an FRN holder's own filing set its type; on the 2026-10-25 file this gives 1,823 government entities, cuts `unclassified` from 815 to 107, and leaves 805 FRNs flagged as person/non-person conflicts (possible ID errors). 62 tests pass.
- Added the ULS license/application parser `teleownermap.ingest.fcc_uls` (2026-10-29/30), with column names generated from FCC's ULS Data File Format (`ingest/uls_columns.py`), a `license_sites` table and license status/date columns, and a streaming bulk writer. Found that transfers and assignments aren't in the per-service application files but in `a_aatc.zip` (1987–2026, with TA consent/consummation dates), where an assignment has no licensee row: the assignee (E) receives the license from the assignor (R). On the Oct 27 copy of `a_aatc.zip` it yields 47.7k assignor, 15.8k transferor and 18.5k transferee links and 58k consent / 54k consummation dates in about 47 s (17 rows with stray `|` skipped and reported; ~3.3 GB peak memory). `l_cell` + `a_cell` load in 30 s. Race, ethnicity and sex fields are dropped; individuals' addresses, phone, fax, email and transmitter sites are hashed. 70 tests pass.

- Added GLEIF ingestion `teleownermap.ingest.gleif` (2026-10-30): staging tables `gleif_entities`, `gleif_relationships`, `gleif_exceptions` for the whole golden copy (sole proprietors' street, city and postal code hashed even in staging), and `promote()`, which walks a recursive parent chain from given LEIs and creates entities, consolidation/fund links (equity only when GLEIF gives a percentage, labeled as not defined as equity; "ultimately consolidated by" kept outside both graphs as a cross-check), reporting-exception attributes, lapsed labels and LEI registration/creation events. - Added GLEIF to the ingest command and staged the full 2026-10-30 golden copy (2026-11-02): 3,479,309 LEI records, 492,254 relationship records and 6,451,622 reporting exceptions in 6.6 min with a 1.52 GB memory peak; the database grew from 6.6 to 7.9 GB (downloads: 0.9 GB). On real data, NTT DoCoMo (legal name 株式会社NTTドコモ, other name "NTT DOCOMO, INC.") resolves to its parent "NTT, Inc." through an active "directly consolidated by" link with no percentage, showing that matching must use other/transliterated names.
- Added guided exhibit import `teleownermap.exhibits` (2026-11-02): lists a filing's exhibits from the newest ownership snapshot (ownership-related first by FCC attachment code I/N or title words, stable numbering, read/unread), prints download steps with the live-lookup warning, and imports a user-downloaded PDF for one chosen exhibit (rejects non-PDFs such as saved error pages, keeps a fingerprinted copy under `data/fcc_exhibits/`, extracts page text with PyMuPDF and counts pages with no text layer). New `exhibit_files` table; PyMuPDF added as a dependency.
- Checked FCC's open-data catalog for FRN registration (CORES) data (2026-11-02): none is published, and no loaded bulk file carries FRN registration dates, so they stay out of timing evidence. FCC's broadband deployment datasets do list a self-reported "Holding Company Name" per provider FRN, a possible future ownership source.
- Added timing percentiles `teleownermap.metrics.timing` (2026-11-02): pair timing (closest pair of events between two entities vs every other pair in the comparison group) and lead time (last event before an outside date vs the group), as the share of the group as close or closer, with group size, a small-group flag below 30, a seeded sample above 200k pairs, and the "group may contain shells" caveat. The display waits for week-5 links. CI now also runs the tests on Python 3.11 and 3.13. 89 tests pass.
- Changed timing's small-group flag to count entities instead of comparisons (2026-11-02): with 9 entities, pair timing has 35 other pairs, which passed a 30-comparison cutoff even though the pairs aren't independent; results now report both counts and flag groups with fewer than 30 entities. 90 tests pass.
